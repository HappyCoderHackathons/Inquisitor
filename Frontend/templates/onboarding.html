Warm-up

This step explains the measurement before any sample starts. A score compares a window with this device's enrollment. It is an anomaly signal, not an identity.

What is collected

  • Keyboard timing summaries: hold times, gaps between presses, pauses, and bursts.
  • Counts for the window, such as how many presses occurred and how long the window lasted.
  • Mouse timing aggregates only when mouse collection is enabled.

What is not collected

  • Typed text, passwords, key names, and the order of individual keys.
  • Screenshots, application names, and page addresses.
  • The pointer path and absolute pointer position.
  • The practice text on Typing Sample. It stays in this browser.

The field names and units are on the privacy page.

Typing Sample

Type in the box if you want a neutral passage to practice on. The words stay in this browser. The page does not save them and does not send them. The agent, when it is running, can send only timing summaries.

Nothing you type here is included in a request.

Natural Activity

Use this PC as you usually would, or play the calibration games. Usable windows are keyboard summaries with at least 30 presses. This demo asks for 30 of them before training.

    Train Model

    Train stays off until each game has its time and the usable windows cover training and calibration. Training uses those summaries, not the practice text.

    Your model

    Retraining collects a new set of game rounds. Monitoring keeps using your current model until you choose to switch. The last round you play is held back to compare both models.

    Compare before switching

    Both models scored the same held-back round, which neither was trained on. A round has only a few windows, so treat this as a check, not an accuracy score.
