THE PROTOTYPE

Play, then see the summary.

Choose an individual game or run a four-game sprint. Keyboard and mouse controls are shown in each game; supported gamepads can also be used.

01 / PLAY

Four ways to play

Aim Trainer, Block Stack, Word Sprint, and Arena Rush each exercise different interactions.

02 / SUMMARIZE

Numbers, not key logs

After a round, the browser sends counts and timing statistics along with the game and score.

03 / REVIEW

See recent rounds

Recent scores and aggregate summaries are stored in a local SQLite database and can be cleared.

PRIVACY & SCOPE

Your words and raw input stay out of the summary.

Game input is handled in the browser and input events are not sent to Flask. Word Sprint does not send the words you type. Only aggregate counts, timing statistics, the selected game, and score are saved locally after a round.

This is an arcade data-collection prototype. It does not include the Windows background agent or the authentication and model pipeline described in the project brief.
