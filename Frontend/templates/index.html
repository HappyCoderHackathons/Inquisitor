CONTINUOUS CHECKS

Timing summaries, not typed content.

Inquisitor watches how you type and how you move the mouse. It compares 30-second summaries of that timing with a model trained on your own enrollment and flags unusual timing. It does not read characters, passwords, or key names.

Create Account Log In

A Windows agent is required. Monitoring runs on the enrolled PC, not in this browser. The arcade remains a local calibration prototype.

WHAT REACHES THE MODEL

Timing summaries flow forward. Typed content does not.

The agent keeps a key identity in memory only long enough to pair a press with its release, then drops it. The model receives one aggregate window.

LIMITATIONS

It detects anomalies, not identity.

A result is a prompt to verify. It is not proof of who is at the keyboard, and a short enrollment does not establish security-grade accuracy.

  • It does not replace Windows login, passwords, MFA, or passkeys.
  • It does not lock the PC, sign out of Windows, or block the keyboard or mouse.
  • It does not name a person from a global population.
  • It does not train one model that works for every person and keyboard.
  • It does not collect typed text, screenshots, clipboard contents, or window titles. The privacy page lists the full prohibition.
  • Collection is opt-in. The agent shows a tray icon with pause and quit, and starts with Windows only if you turn that on.
