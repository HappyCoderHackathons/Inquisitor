PRIVACY

Exact fields, and nothing else.

Only feature windows leave the PC. The Windows agent sends version 4: keyboard and mouse aggregates for each 30 seconds of activity. Versions 1 and 2 are the browser arcade's formats; version 2 adds mouse aggregates when its mouse collection is enabled. Extra fields are rejected. A score compares a window with that device's enrollment. It is an anomaly signal, not an identity. See what this does not claim.

Window fields

These fields describe the window. They do not name a key or a screen position.

Windows agent features (version 4)

Every agent window has these fifteen fields, computed over 30 seconds. Windows with no presses, no movement, and no clicks are not sent. Mouse movement is summed into 20 ms segments of relative sensor counts, not screen pixels. Absolute pointer coordinates, click targets, and key names are not fields.

Browser arcade keyboard features (versions 1 and 2)

Browser versions 1 and 2 require these eleven fields. Pauses are inter-press gaps longer than 1,000 ms. Standard deviations use the population formula. The 90th percentile uses nearest rank. Hold percentiles, press_interval_p50_ms, and burst_length_mean are not accepted and are not collected.

What is never collected

The agent may see timing while a password is typed. It still must not record the password. Pause collection before typing one if that timing should stay out of the window. Key identity is discarded before the window is saved.

  • Character sequences, typed text, passwords, search queries, and clipboard contents.
  • Raw scan-code logs, virtual-key-code logs, key names, and per-key frequency tables.
  • Ordered keydown and keyup event streams.
  • Screenshots, application names, browser URLs, and visible page content.
  • Full cursor paths and absolute pointer positions.
  • Input from another person's machine without their informed consent.
